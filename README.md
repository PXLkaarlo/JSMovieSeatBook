# Overview

This is an assingment that focusus on Frontend with some Backend.
The main objective with this assignment is to allow the user to pick a movie and pick their seat of choice.
While they choose their seat they will also be able to see how much it will cost in total.
The second part of the objective is to have the movie options come directly from a database, along with prices.
